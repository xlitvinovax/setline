# Setline · прототип

Откройте `index.html` в браузере или запустите из этой папки `python3 -m http.server 8000` и перейдите на http://localhost:8000. Зависимостей и сборки нет. Для сохранения данных используйте один и тот же браузер и адрес.

В `index.html` разметка, стили и логика. Демо-упражнения описаны в `legs` и `upper`, пример истории — в `sample`. В разделе «Планы» шаблоны можно создать и изменить прямо из интерфейса. Данные хранятся в этом браузере под ключом `setline-demo-v1`. Регистрация, облачная синхронизация и загрузка страницы офлайн запланированы для MVP.

Для публикации демо загрузите оба файла в корень ветки `main` своего репозитория. Выберите в GitHub **Settings → Pages → Deploy from a branch → main → / (root) → Save**. GitHub покажет адрес после завершения публикации. Деплой использует содержимое `main`.
